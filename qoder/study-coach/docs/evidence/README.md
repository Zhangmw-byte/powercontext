## 图片可证实的验收点

- 学习记录在浏览器中保存并显示(含中文),保存后有成功提示(10)。
- 记忆验证视图通过真实 SDK 回查正文与 `entry_id`/`entry_version_id`/`revision`(05)。
- 两个学习者数据隔离(B 视图为空)(06)。
- 服务停止并重启后学习者 A 的记录仍在(07)。
- 学习偏好表单填入中文值并展示(08)。
- 复习清单**实际条目、排序(薄弱优先)、推荐理由、预算占用**均在浏览器呈现,且明示规则生成、未调用大模型(09);清单预算 20 与偏好 08 的 20 分钟一致。
